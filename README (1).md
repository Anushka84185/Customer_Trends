# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior using transactional data from 3,900 purchases across multiple product categories.  
The main objective is to identify customer spending patterns, product preferences, subscription trends, and business insights using Python, SQL, PostgreSQL, and Power BI.

---

## Technologies Used

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI

---

## Dataset Information

- Total Rows: 3,900
- Total Columns: 18

### Key Features
- Customer demographics
- Product categories
- Purchase amount
- Subscription status
- Discount usage
- Review ratings
- Shipping type
- Purchase frequency

---

## Data Cleaning & Preprocessing

The following preprocessing steps were performed:

- Handled missing values in review ratings
- Renamed columns into snake_case format
- Created age group categories
- Created purchase frequency features
- Removed redundant columns
- Loaded cleaned data into PostgreSQL

---

## Exploratory Data Analysis (EDA)

Performed analysis using Python and SQL to answer important business questions such as:

1. Revenue by Gender
2. High-Spending Discount Users
3. Top Rated Products
4. Shipping Type Comparison
5. Subscribers vs Non-Subscribers
6. Discount-Dependent Products
7. Customer Segmentation
8. Top Products by Category
9. Repeat Buyers & Subscription Analysis
10. Revenue by Age Group

---

## Dashboard

An interactive Power BI dashboard was created to visualize:

- Customer distribution
- Revenue trends
- Product category performance
- Subscription insights
- Age group analysis
- Sales comparison
